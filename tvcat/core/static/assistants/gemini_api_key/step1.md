# Acceder a la plataforma Google Studio

En esta guía veremos como obtener una API KEY para poder añadir funcionalidad de IA a TVCat, como por ejemplo, generar descripciones de colecciones y mas.

Vamos al sitio [Google AI Studio](https://aistudio.google.com/) y hacemos click en el botón **"Get Started"** para hacer login con nuestra cuenta google si no estamos logeados aún.
