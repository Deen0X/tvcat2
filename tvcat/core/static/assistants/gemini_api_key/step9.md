# Selección de modelo a utilizar

Puedes consultar los modelos disponibles actualmente en [este enlace](https://ai.google.dev/gemini-api/docs/models). 

Los modelos van rotando cada cierto tiempo, y no existe una forma automática de configurar cual usar, por lo que tienes que consultar cuales son los disopnibles. Como recomendación, NO utilices el último en salir, por que tendrás menos usos gratis que uno mas antiguo. No selecciones ni el mas antiguo de los que aparecen en la lista, ni el mas nuevo. Vete a algo que esté en el medio. No busques nada complejo que genere imágenes, etc. solo necesitamos texto.

Y también céntrate en modelos flash. no necesitamos ni nivel de razonamiento ni resolver sentencias complejas.

En este listado, el último es **Gemini 3.8 Flash**, y el mas antiguo de los que nos interesan es el **Gemini 3.1 Flash Live". Para este caso estoy utilizando **Gemini 3.6 Flash** que creo que es suficente para lo que necesitamos.
