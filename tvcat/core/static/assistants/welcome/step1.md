# Asistente de ejemplo

Este es un asistente de muestra. Cada paso es un fichero `stepN.md` en esta
misma carpeta (más `stepN.png` opcional con el mismo nombre base).

Puedes usar **negrita**, *cursiva*, `código` y [enlaces](https://example.com).

Tags especiales:

- {step:2:Ir al paso 2} para saltar a otro paso.
- {goto:tab:enricher:Abrir Enriquecedor} para abrir una pestaña de ajustes.
- {goto:section:collections:Ver colecciones} para abrir una sección.
